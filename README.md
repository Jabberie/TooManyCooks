# TooManyCooks

Too Many Cooks is a lightweight World of Warcraft addon that helps with cooking events by detecting the cook's instructions and clearly highlighting which ingredient to add next.

## Current Support

### Suspicious Stew — The Coiled Isle

Too Many Cooks listens for the Witherbark Cook's instructions and displays a simple ingredient panel showing what you need to add next.

Features include:

- Automatic event detection
- Highlights the requested ingredient
- Tracks progress through the 6 ingredient requests
- Flip/mirror layout to support either side of the cooking area
- Movable interface
- Automatic reset when the stew fails
- Automatically hides when the event is completed
- Only activates in the relevant area

## Development Status

Too Many Cooks was initially vibe-coded as a small quality-of-life addon for the Suspicious Stew event. It has been tested in-game, but bugs and edge cases are possible.

Support for other similar cooking and ingredient-selection activities is planned.

Bug reports, fixes, and suggestions for other activities are welcome.
